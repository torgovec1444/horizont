# Horizont: сайт навчального проєкту

Статичний сайт вигаданої онлайн-школи німецької мови Horizont. Навчальний проєкт з курсу «Комунікації в Інтернет-маркетингу». Сервер не потрібен: сайт відкривається подвійним кліком по `index.html`.

## Структура

- `index.html` - лендинг за главами I-IX та епілог
- `pro-proyekt/index.html` - сторінка «Про проєкт» (що на сайті умовне, джерела зображень)
- `cookie/index.html` - політика cookie
- `assets/css/style.css`, `assets/js/main.js`, `assets/js/pre.js` - стилі та поведінка
- `assets/fonts/` - шрифти Lora, Mulish, IM Fell English (SIL OFL), лежать локально
- `assets/img/` - зображення та текстури
- `assets/pdf/plan-A1.pdf` ... `plan-B2.pdf` - плани на 30 днів (лід-магніт)
- `robots.txt`, `sitemap.xml` - службові файли із заглушкою домену

## Як викласти на GitHub Pages

1. Створи на github.com новий публічний репозиторій, наприклад `horizont`.
2. Завантаж у нього вміст цієї папки: кнопка Add file, далі Upload files. Перетягни всі файли й папки, натисни Commit changes. Файл `index.html` має лежати в корені репозиторію.
3. Відкрий Settings, розділ Pages. У полі Source обери Deploy from a branch, гілка `main`, папка `/ (root)`. Натисни Save.
4. За одну-дві хвилини сайт з'явиться за адресою `https://ТВІЙ-ЛОГІН.github.io/horizont/`.

Порожній файл `.nojekyll` потрібен, щоб GitHub віддавав файли як є. Якщо при завантаженні через браузер він загубився, сайт усе одно працюватиме.

## Що треба замінити (заглушки)

| Що | Де | Зараз |
|---|---|---|
| Адреса сайту | `sitemap.xml`, `robots.txt` | `https://example.github.io/horizont/` |
| Ідентифікатор Google Analytics | `assets/js/main.js`, рядок `GA_MEASUREMENT_ID` | `GA_MEASUREMENT_ID` (аналітика не вантажиться) |
| Пошта для контактів | `index.html`, `pro-proyekt/index.html`, `cookie/index.html` | `hello@horizont.example` |
| Соцмережі | немає на сайті | додати посилання в `index.html`, блок `.foot` |

Google Analytics вмикається лише за двох умов: відвідувач натиснув «Прийняти всі» і в `main.js` стоїть справжній ідентифікатор виду `G-XXXXXXX`.

## Налаштування в main.js

На початку файлу є об'єкт `CONFIG`:

- `mobileGlow` - м'яка підсвітка кнопок на телефоні й планшеті (`false` вимикає її повністю);
- `idlePokes` - скільки разів рука в шапці ворухнеться до першої прокрутки.

Рука-вказівник літає лише на комп'ютері з мишею (ширина вікна від 1024 px) і не рухається, якщо в системі ввімкнено зменшення руху.

## Форми

Форми нічого не надсилають. Після натискання кнопки сторінка показує повідомлення, а форма плану ще й віддає PDF потрібного рівня.
